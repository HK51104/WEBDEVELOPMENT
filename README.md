# 🌐 Web Development

A collection of **Web Development practice projects, exercises, and experiments** built while learning modern frontend development fundamentals.

This repository documents my progression from basic **HTML and CSS** concepts to responsive layouts, animations, media elements, SVG, grids, and small frontend projects.

---

## 🚀 Overview

This repository is primarily a hands-on learning workspace built around the **Sigma Web Development Course**, with additional experimentation and implementation of concepts through individual exercises.

Instead of keeping everything in a single project, concepts are separated into focused exercises so that each topic can be practiced independently.

```text
HTML
  ↓
CSS
  ↓
Layouts
  ↓
Responsive Design
  ↓
Animations
  ↓
Media & SVG
  ↓
Mini Projects
  ↓
Frontend Development
```
